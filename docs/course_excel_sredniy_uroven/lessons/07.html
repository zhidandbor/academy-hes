Тема 1: Excel: от формул к аналитике и визуализации

Аналитика и визуализация данных в Excel

Фильтры и срезы

Ильфак ВалиевЭксперт Excel, инженер-строитель

Андрей, привет! На этом уроке разберем, как сделать твои отчеты интерактивными и удобными — с помощью фильтров и срезов в сводных таблицах. Это особенно важно, когда у тебя большой отчет, и ты хочешь в два клика отфильтровать данные по объекту, подрядчику или виду работ. Срезы превращают скучную таблицу в наглядный и понятный инструмент. После этого урока ты сможешь использовать стандартные фильтры, добавлять красивые кликабельные срезы, управлять сразу несколькими сводными таблицами с помощью хронологической шкалы. Поехали!

Что такое фильтры

Фильтры в сводной таблице позволяют отображать только нужные данные, скрывая все остальное. Их можно использовать:

  1. в области «Фильтры» — фильтр применяется ко всей сводной таблице;
  2. в строках или столбцах — фильтрация работает в пределах выбранной иерархии; 
  3. через интерфейс Excel — например, при нажатии на стрелку рядом с заголовком поля.

Плюсы:
Стандартный, привычный интерфейс.    
Подходит для любых типов данных.    

Минусы:
Меньшая наглядность.    
Требует несколько кликов для смены условий.    

Что такое срезы (Slicers)

Срезы — это визуальные элементы управления, которые дают возможность фильтровать сводную таблицу с помощью наглядных кнопок.

Пример

У тебя есть список работ по объектам. Срез позволяет в один клик показать только данные по «ЖК Северный», без необходимости открывать фильтр и прокручивать список.

Срез можно создать так:

  1. Выдели сводную таблицу.
  2. Вкладка «Анализ сводной таблицы» → «Вставить срез».
  3. Выбери нужные поля (например, «Объект», «Подрядчик», «Вид работ»).
  4. Размести срезы рядом с таблицей. Готово!

Хронологическая шкала (Timeline)

Это специальный вид среза, предназначенный для фильтрации по дате.

Как создать:

  1. Вкладка «Анализ сводной таблицы» → «Вставить временную шкалу».
  2. Выбери поле с типом «Дата».
  3. Появится горизонтальная шкала, по которой можно фильтровать данные по:    
    году
    кварталу
    месяцу
    дню

Лучше использовать «Месяц» или «Квартал» — они дают хороший баланс между детализацией и обзорностью.

💡 Полезные нюансы и советы

Совет 1. Не злоупотребляй фильтрами в нескольких зонах одновременно.
Если у тебя и срез, и фильтр по одному полю — легко запутаться, почему данные не отображаются. Лучше использовать только один метод фильтрации для одного и того же поля.

Совет 2. Срезы можно применять к нескольким сводным таблицам.
Если у тебя несколько сводных, построенных на одном источнике данных, ты можешь выделить срез → Подключить к другим таблицам через «Подключенные сводные таблицы».

Совет 3. Меняй стиль среза.
Правой кнопкой по срезу → «Стили срезов». Это особенно полезно, если ты хочешь отделить визуально, например, срезы по объектам и по видам работ.

Совет 4. Не забывай о прокрутке в срезах.
Если у тебя 10+ объектов — срез превратится в длинную панель. Чтобы не перегружать лист, уменьши высоту и включи вертикальную прокрутку.

Совет 5. Используй кнопку «Очистить фильтр» в срезе.
Это быстрый способ сбросить все фильтрации и вернуться к полной картине данных.

Совет 6. Для фильтрации нескольких значений удерживай CTRL.
Можно выбрать сразу несколько подрядчиков, объектов или месяцев в срезе. Это удобно при сравнении.

Совет 7. Шкала даты работает только с полем формата «Дата».  
Убедись, что поле действительно в формате даты, иначе временная шкала не появится в списке доступных.

Совет 8. Не скрывай срезы при печати.
Если ты печатаешь отчет, убедись, что срезы не перекрывают важные области — или отключи их отображение в режиме печати.

Практическая часть

  1. Исходная таблица — как в прошлом уроке (объекты, работы, суммы, даты).
  2. Построй сводную таблицу:
    Строки: Вид работ
    Значения: Сумма расходов
  3. Добавь фильтр по Объекту:
    Перетащи поле «Объект» в область «Фильтры»
    Проверь, как меняется сводная при выборе разных объектов
  4. Добавь срез:
    Выдели сводную → Вкладка «Анализ сводной таблицы» → «Вставить срез»
    Выбери поле «Объект»
    Кликай по кнопкам в срезе и смотрите, как динамически меняются данные
  5. Добавь хронологическую шкалу:
    Также во вкладке «Анализ сводной таблицы» → «Вставить временную шкалу»
    Выбери поле «Дата»
    Можно фильтровать по годам, кварталам, месяцам
