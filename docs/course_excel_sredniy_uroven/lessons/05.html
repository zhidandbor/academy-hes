Тема 1: Excel: от формул к аналитике и визуализации

Работа с формулами в Excel

ИНДЕКС + ПОИСКПОЗ

Ильфак ВалиевЭксперт Excel, инженер-строитель

Андрей, на очереди — две мощные функции Excel, которые вместе образуют самый гибкий способ поиска данных: ИНДЕКС и ПОИСКПОЗ. В отличие от ВПР, эти функции позволяют искать в любую сторону — и влево, и вправо, и даже в разных таблицах. С их помощью ты легко сможешь найти, например, характеристики арматуры по ГОСТ, марку бетона по классу прочности или данные из сложных справочников. Эти функции часто используют профессионалы, потому что они надежнее и универсальнее. Разберемся, как это работает.

Что делают эти функции

ИНДЕКС() — возвращает значение из таблицы по номеру строки и/или столбца  
ПОИСКПОЗ() — находит позицию значения в диапазоне

В связке они позволяют искать данные в любую сторону (в отличие от ВПР, который ищет только справа).

Синтаксис:

ИНДЕКС()

=ИНДЕКС(диапазон; номер_строки; [номер_столбца])

Пример 1.

=ИНДЕКС(C2:C10; 3)

→ Возвращает значение из 3-й строки диапазона C2:C10

ПОИСКПОЗ()

=ПОИСКПОЗ(значение; диапазон; [тип_сопоставления])

  • тип_сопоставления: обычно 0 — точное совпадение

Пример 2.

=ПОИСКПОЗ(«Бетон М300»; A2:A10; 0)

→ Вернет номер строки, где найден «Бетон М300»

Комбинация ИНДЕКС + ПОИСКПОЗ

=ИНДЕКС(C2:C10; ПОИСКПОЗ(«Бетон М300»; A2:A10; 0))

  • Находим строку, где «Бетон М300»
  • Берем из этой строки значение из столбца C

Результат: цена этого материала

Применение в строительстве
Почему ИНДЕКС + ПОИСКПОЗ лучше ВПР

Важные нюансы:

  1. ПОИСКПОЗ возвращает позицию относительно диапазона, не абсолютную строку листа
  2. Всегда проверяй, что диапазоны в ИНДЕКС и ПОИСКПОЗ одной длины по строкам
  3. Используй 0 как третий аргумент в ПОИСКПОЗ — это поиск точного совпадения

Держи справочники на отдельном листе (Справочник!A2:C100)
Используй имена диапазонов или таблицы Excel, чтобы формулы были читаемыми
Для надежности можно добавить ЕСЛИОШИБКА(...), чтобы скрыть ошибку при отсутствии значения
=ЕСЛИОШИБКА(ИНДЕКС(...); "")

Практическая часть

  1. Таблица: ГОСТ на арматуру. В первом столбце — диаметр, во втором — ГОСТ, в третьем — масса 1 м.
  2. Задача: по диаметру найти массу 1 м арматуры.
    =ИНДЕКС(C2:C100; ПОИСКПОЗ(F2; A2:A100; 0)), где F2 — введенный диаметр.
  3. Заменяем жесткие значения на ссылки на ячейки.
  4. Добавляем защиту от ошибок:
    =ЕСЛИОШИБКА(...; "Нет данных")
