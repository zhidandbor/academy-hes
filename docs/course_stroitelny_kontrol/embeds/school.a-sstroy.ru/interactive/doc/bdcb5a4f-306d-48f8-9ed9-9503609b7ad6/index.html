Какие инструменты можно использовать при визуальном контроле качества

Подготовлено в

Штангенциркуль

Подойдет для проверки толщин стенок и диаметров.

Простой в использовании инструмент, который позволит убрать сомнения в номенклатуре применяемого материала.

Рулетка (1м – 5м)

Это карманный инструмент, который желательно брать с собой на объект вместе с телефоном. Подойдет для проверки практически любых материалов

Рулетка (10м-50м)

Этот вариант подойдет для проверки труб, арматуры, свай, пиломатериалов и т.п. Данные должны быть внесены в журнал входного контроля той датой, которой они были приняты на объекте
