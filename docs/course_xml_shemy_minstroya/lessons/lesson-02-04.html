Системы и сервисы для ИД в XML

На данный момент бесплатных сервисов, чтобы формировать ИД, по аналогии, например, с сервисами ГГЭ, нет. ИД в электронном виде в формате XML можно формировать с инфосистемами, которые позволяют создавать акты, соответствующие XML-схемам Минстроя. Например, Exon, ЦУС, Dacon, «Адепт». Также есть другие сервисы с такими функциями. Например, docxml.ru.

То есть ИД в формате XML оформляют, когда заказчик решает вести ИД в электронном виде или это обязательно нужно делать. Например, для проектов многоквартирных домов и иных объектов по ДДУ.

Информационную систему для ИД в электронном виде выбирает заказчик. Если заказчик государственный, чаще используют ИСУП без функции формировать документы. Поэтому подрядчик должен выбрать систему, которая будет иметь интеграцию с ИСУП. Когда заключаете договор с поставщиком инфосистемы для ИД заранее, зафиксируйте три условия:

  1. Система должна формировать документы только на основе утвержденных XML-схем Минстроя.
  2. Поставщик системы должен своевременно обновлять XML-схемы, если их изменили или утвердили новые редакции.
  3. Важно закрепить, что система должна быть адаптирована к новым версиям схем не позднее даты их вступления в силу.

Пример. Формулировка для договора подряда об использовании XML-схем

«При формировании исполнительной документации в электронной форме Исполнитель обязан обеспечить использование исключительно XML-схем, утвержденных и опубликованных уполномоченными федеральными органами исполнительной власти (в том числе Минстроем) и размещенных на официальных источниках. Информационная система должна: поддерживать формирование документов строго в соответствии с действующими версиями XML-схем; обеспечивать своевременное обновление XML-схем при опубликовании новых редакций; быть адаптированной к применению новых или измененных XML-схем не позднее даты их вступления в силу; обеспечивать корректную работу ранее сформированных документов в версиях схем, действовавших на момент их создания. Исполнитель несет ответственность за несоответствие сформированных документов действующим XML-схемам, повлекшее невозможность их использования, передачи или приема уполномоченными органами, в том числе при прохождении экспертизы или ведении информационной модели объекта капитального строительства».
