Как работать с анализом данных

Фильтрация

Ильфак ВалиевЭксперт Excel, инженер-строитель

Андрей, добро пожаловать на новый урок! В этом уроке мы познакомимся с таким инструментом Excel, как фильтрация данных. Для чего же нам нужно фильтровать данные? Представь, что у тебя есть таблица с большим количеством материалов для строительного проекта, и тебе нужно быстро найти те, которые соответствуют определенным критериям — например, бетон марки М300. Именно для этого и существует функция фильтрации! В процессе урока мы научимся использовать автофильтр, чтобы отбирать только нужные данные по заданным критериям. По завершении урока ты сможешь настроить фильтры для поиска конкретных материалов и значительно ускорить работу с большими таблицами, не тратя время на лишнюю информацию. Начнем!

Что такое фильтрация данных

Фильтрация данных в Excel позволяет скрывать строки, которые не соответствуют заданным условиям, и отображать только те, которые нам нужны. Например, если у тебя есть список всех материалов, а нужно видеть только бетон марки М300, ты можешь легко отфильтровать этот список и увидеть только нужные строки.

Что дает фильтрация:

  1. Быстрое нахождение нужных данных.
  2. Упрощение работы с большими таблицами.
  3. Отбор данных по множеству критериев, таких как цена, количество или другие параметры.

Как работает автофильтр

Как включить автофильтр:

  1. Выбираем таблицу данных.
  2. Переходим во вкладку «Данные» и нажимаем кнопку «Фильтр». Теперь в заголовках столбцов появятся стрелки, с помощью которых можно фильтровать данные.

Как фильтровать данные по условию:

  1. Для фильтрации по одному столбцу, нажимаем на стрелку в нужном столбце и выбираем условия фильтрации (например, «Только значения больше 5000» или «Только значение Бетон М300»).
  2. Ты можетешь комбинировать фильтры для более точного отбора.

Практическая часть

Теперь давай применим теорию на практике. Возьмем нашу таблицу строительных материалов, чтобы отфильтровать те, которые относятся к бетону марки М300:

Чтобы отфильтровать только бетон марки М300, сначала выделяем таблицу. Затем идем во вкладку «Данные» и нажимаем кнопку «Фильтр». После этого в заголовках появляются стрелки, с помощью которых можно выбирать фильтры. Нажимаем стрелку в столбце «Наименование», ищем марку бетона М300 и ставим галочку напротив этого значения. Теперь мы видим только строки с бетоном марки М300! Это очень удобно, если нужно работать только с определенной группой материалов.

Отлично! Теперь ты знаешь, как фильтровать данные в Excel и как использовать автофильтр для быстрой работы с таблицами. Удачи в выполнении домашнего задания!
