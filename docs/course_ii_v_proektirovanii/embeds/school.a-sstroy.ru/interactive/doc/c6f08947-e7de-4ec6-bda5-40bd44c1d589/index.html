Примеры промптов для инженерных визуализаций

Подготовлено в

ОВ. Пример реализации вентиляционной решетки:

«Вентиляционная решетка прямоугольная, белая, пластик, на белой стене, современный офис, крупный план, фотореализм»

ОВ. Пример реализации радиатора:

«Стальной панельный радиатор под окном, современная квартира, светлые тона, фотореализм»

ВК. Пример реализации труб водоснабжения:

«Медные трубы водоснабжения, закреплены на стене, современная ванная комната, крупный план, фотореализм»

ВК. Пример реализации насосной станции:

«Насосная станция водоснабжения в шкафу, чистое техническое помещение, реалистичное 3D-изображение»

ВК. Схема разводки водоснабжения:

«Схема водоснабжения квартиры, трубопроводы синие (холодная вода) и красные (горячая), технический рисунок, белый фон»

ЭОМ. Пример реализации светильников:

«Трековые светильники на потолке офиса, современный интерьер, фотореализм»

ЭОМ. Пример реализации розеток и выключателей:

«Розетка с USB-портами в светлой стене, крупный план, фотореализм»

ЭОМ. Пример реализации электрощитков:

«Электрощиток в нише, аккуратная разводка, техническое помещение, реалистичное фото»

ЭОМ. Пример реализации кабельного лотка:

«Кабельный лоток в подвесном потолке, аккуратная укладка кабелей, техническое помещение, фотореализм»

ЭОМ. Пример реализации датчик движения:

«Датчик движения на потолке, современный офис, крупный план, фотореализм»
