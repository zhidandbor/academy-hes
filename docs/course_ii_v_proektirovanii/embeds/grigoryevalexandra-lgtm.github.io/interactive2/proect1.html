Grok
Grok сразу уточняет недостающие данные и не переходит к созданию шаблона пояснительной записки.
Qwen
Qwen же не только запрашивает недостающие ему данные, но и готовит шаблон на основе уже имеющихся данных. Тем самым – в следующем запросе можно уже скорректировать и форму представления данных пояснительной записки.
