Каждый курс содержит `release.json` с составом публикации, происхождением файлов, контрольными суммами вынесенных материалов и известными ограничениями. Исходные снимки и проверочные отчёты хранятся в проекте HES. MBA и курс по закупкам на момент выпуска подготовлены из локальных архивов HES; их манифесты зафиксированы контрольными суммами в `release.json`.

Сохранённые страницы не воспроизводят личный кабинет, серверную проверку ответов и результаты тестов. Внешние видео и упражнения могут требовать исходной платформы. Нормативные замечания к курсу по закупкам отмечены в его страницах и исходном архиве.
